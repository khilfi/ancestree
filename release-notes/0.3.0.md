The guide, and a simpler AncesTree: the copy to edit retires, now that relatives keep their own AncesTree in step through the family folder.

- **[The guide](https://github.com/khilfi/ancestree/blob/main/GUIDE.md)**, for the keeper and for relatives, on Windows, the Mac and Linux: installing past each warning, the first start, starting the family folder or joining it, changes and answers, updates, and what to do when something goes wrong.
- **The copy to edit is retired.** **Export → Copy to edit** and **Settings → Import → Changes from a copy** are gone: relatives join the family folder instead. A copy to edit already sent still opens, but what's changed in it can't come back. View-only copies stay, for phones and for anyone who won't install AncesTree. Changes brought in from copies before can still be taken back.
- **Joining keeps what was there.** The first time the family arrives on a relative's computer, whatever was on it before is kept in a backup, under **Settings → Backups**.
- **On a Mac**, choosing AncesTree in the Dock brings its window back.
- **Settings shows what waits for you**, from anywhere in AncesTree: the computers asking to join, and relatives' changes waiting.
- **Earlier imports**, under **Settings → Import**, name the computer a relative's changes came from.

When you sign in to Google from AncesTree, Google says it hasn't verified the app: AncesTree is made for one family, so it isn't. Choose **Advanced**, then **Go to AncesTree (unsafe)**.

**If you installed 0.1.0, 0.1.1 or 0.2.0**, install 0.3.0 from this page by hand: those versions don't know the key updates are signed with now, so they won't update themselves. 0.2.1 updates itself.
